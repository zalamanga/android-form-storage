# Catatan sumber

Source utama berasal dari folder lokal aplikasiform2. Namespace com.rapik.example.aplikasiform, gambar, ikon, dan struktur layar asal dipertahankan. Perbaikan mencakup launcher, pendaftaran akun, sesi, hash/migrasi password, validasi form, serta hasil penyimpanan dan pembacaan file. Sumber asli tidak diubah.

Tidak ditemukan LICENSE proyek, metadata upstream, atau atribusi yang menetapkan izin seluruh aset. Tidak diberikan lisensi baru atas source/aset asal. Gradle Wrapper memiliki header Apache 2.0 sendiri; dependency AndroidX, Material Components, dan JUnit mengikuti lisensinya masing-masing.
